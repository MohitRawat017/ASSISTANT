# Feature Specifications

This directory holds focused specifications for individual features or
milestones. Each spec is the implementation source of truth for its feature.

## How to Use

1. Copy `feature-template/spec.md` to a new folder named after your feature
   (e.g. `user-auth/spec.md`).
2. Fill in the goal, non-goals, requirements, edge cases, and acceptance
   criteria.
3. Keep the spec linked from the roadmap's current work while it is in
   progress.
4. Remove the link when the feature is complete; keep the spec as a
   historical record.

## Naming

- One folder per feature: `kebab-case-name/`
- One `spec.md` per folder.
- Do not nest specs inside specs.
